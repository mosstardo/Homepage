# Landing Page

A landing page built with HTML and CSS as part of **The Odin Project** curriculum.

## About the Project

This project focuses on recreating a landing page from a given design, helping me practice fundamental front-end development concepts and improve my understanding of page layouts.

## Built With

* HTML5
* CSS3
* Flexbox

## What I Learned

Throughout this project, I practiced:

* Structuring web pages with semantic HTML.
* Building responsive layouts using Flexbox.
* Organizing and reusing CSS classes.
* Positioning and aligning elements effectively.
* Creating clean and maintainable code.

## Challenges

One of the biggest challenges was understanding how parent and child elements interact when using Flexbox to build complex layouts.
